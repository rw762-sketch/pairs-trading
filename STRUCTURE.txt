================================================================================
WORKFLOW
================================================================================

1. DATA ACQUISITION (data_fetcher.py)
   ├── Fetch S&P 500 data from Yahoo Finance (3 years)
   ├── Clean: Remove stocks with missing data
   └── Split: 70% training, 30% testing

2. PAIR IDENTIFICATION (cointegration.py)
   ├── Test all pairs for cointegration
   ├── Engle-Granger two-step method
   ├── ADF test on residuals
   └── Output: List of cointegrated pairs

3. SIGNAL GENERATION (signal_generation.py)
   ├── Calculate hedge ratio (linear regression)
   ├── Calculate spread = Price_A - β*Price_B
   ├── Calculate z-score = (spread - mean) / std
   └── Generate signals: Buy when z < -2, Sell when z > +2

4. BACKTESTING (backtester.py)
   ├── Simulate entry/exit based on signals
   ├── Apply transaction costs (0.1%)
   ├── Track position P&L
   └── Calculate metrics: Sharpe, max drawdown, win rate

5. ANALYSIS & VISUALIZATION (visualization.py)
   ├── Plot equity curves
   ├── Show drawdown analysis
   ├── Display spread & z-score charts
   ├── Create cointegration heatmap
   └── Generate comprehensive report

6. OPTIMIZATION (parameter_optimization.py)
   ├── Test different parameter combinations
   ├── Compare in-sample vs out-of-sample
   └── Detect overfitting

================================================================================
KEY METRICS EXPLAINED
================================================================================

Sharpe Ratio
└─ Risk-adjusted return
   0.5 = OK, 1.0 = Good, 2.0+ = Excellent
   Target: > 1.0

Annualized Return
└─ Total profit scaled to yearly basis
   Target: > 10% (after costs)

Max Drawdown
└─ Largest peak-to-trough decline
   Target: < 20%

Win Rate
└─ Percentage of profitable trades
   Target: > 50%

Transaction Cost
└─ Cost per trade (typically 0.1%)
   Over full round-trip: 0.2%

================================================================================
COMMON ISSUES & SOLUTIONS
================================================================================

Issue: "No pairs found"
→ Solution: Lower coint_threshold (0.05 → 0.10) in config.py
           Increase num_stocks to 100+

Issue: "Poor out-of-sample performance"
→ Solution: Indicates overfitting - likely pairs lose cointegration
           Use stricter cointegration threshold
           Reduce entry signal strictness

Issue: "Very low returns"
→ Solution: Transaction costs destroy small profits
           Check if strategy even beats buy-and-hold
           Require larger spreads before trading

Issue: "Slow execution"
→ Solution: Cointegration testing is O(n²)
           Reduce num_stocks for faster iteration
           50 stocks = 5 min, 100+ stocks = 20+ min
